# Lettertypen

Lokaal meegeleverd zodat de app offline werkt en de CSP (`font-src 'self'`) niet versoepeld hoeft te worden.

- **Manrope** (400, 500, 600, 700, 800): lopende tekst en UI
- **Chakra Petch** (600, 700): koppen en grote cijfers

Beide zijn open-source onder de SIL Open Font License 1.1.
